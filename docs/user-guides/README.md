## Core Workflows

### First-time user workflow

1. Open the VBase landing page.
2. Select `Get Started`.
3. Sign in or create an account.
4. Open the dashboard.
5. Create your first workspace or accept an invitation.
6. Enter a workspace and start collaborating.

### Team onboarding workflow

1. Create a workspace.
2. Open workspace settings or the invite page.
3. Send invitations to team members.
4. Team members accept from the Invitations page.
5. Create rooms based on the work your team needs to do.

---

## Product Limits At A Glance

- A user can own up to 5 workspaces.
- A workspace can contain up to 10 rooms.
- A workspace can contain up to 10 members.
- Only 1 conference room is allowed per workspace.
- A conference room can host up to 3 concurrent meeting sessions.

---

## Troubleshooting And Support

If something does not work as expected:

1. Refresh the page and try again.
2. Confirm that you are signed in with the correct account.
3. Check whether you are in the correct workspace.
4. Move to the relevant guide page for that feature.

For onboarding issues, start with [Getting Started with VBase](./01-getting-started.md).
